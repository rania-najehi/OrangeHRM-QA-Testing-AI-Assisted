# 🧪 OrangeHRM — Functional Testing Project (AI-Powered)

## 📌 Overview
This repository contains a complete **manual functional testing project** 
for OrangeHRM, an open-source Human Resources Management System (HRMS).
The goal of this project is to ensure the quality and reliability of core 
HR functionalities through structured testing methodologies, 
enhanced with **AI-assisted test design using Claude by Anthropic**.

## 🎯 Objectives
- Validate core functional modules of OrangeHRM
- Design comprehensive test cases based on real user stories
- Identify and document defects with clear reproduction steps
- Demonstrate AI integration in the QA workflow
- Validate database integrity through SQL queries
